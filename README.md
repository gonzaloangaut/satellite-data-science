# Satellite Data Science

Data science portfolio project analyzing satellite and space-object data through exploratory analysis, data curation, and machine learning.

## Project Structure

The project is organized into three stages:

1. **Exploratory Data Analysis** — orbital characteristics, object populations, launch history, responsible entities, and estimated object size.
2. **Data Cleaning and Curation** — preparation and validation of the datasets for modeling.
3. **Supervised and Unsupervised Learning** — predictive modeling and clustering of satellite data.

## Data

The raw datasets are not stored in this repository. They are retrieved programmatically from versioned external sources to support reproducibility.
